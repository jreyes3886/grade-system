# grade-system
Grade System for Final Project in I-ACSAD. To be passed on 11/25/26
## Features
- Add a student with grades for 2 semesters
- Update an existing grade
- Search for a student
- View each semester's average and the yearly average
- Input validation (grades must be 0 to 100)
- Cancel option while entering data

## How to Run
1. Download the file and save as all files.
2. Open `GradeSystem.java` in VS Code
3. Run the code

## Notes
- Yearly average = average of the two semester averages.
- Preloaded sample students are included.
